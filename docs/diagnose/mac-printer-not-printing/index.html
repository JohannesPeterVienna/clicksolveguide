Printer not printing from a Mac: guided checks

On a Mac, the print queue window usually says what is wrong – if you know where to look. Paused, not connected, or jobs that disappear without printing: each points to a different layer. The diagnosis starts there and saves the printing-system reset for the very end.

    Start with the status line
    


    Every printer on a Mac has its own queue window. It opens automatically from the Dock while a job is printing, or from macOS 13 Ventura or laterSystem Settings > Printers & Scanners > (your printer) > Printer Queue…. The line at the top of that window is the most useful piece of information you have: it reflects what macOS knows about the printer at that moment.
    

    A paused queue is a Mac-side state – macOS stopped sending because an earlier job failed, and it waits for you. A “not connected” type of message means the Mac can’t reach the printer at all, so the connection, the router or the printer’s network settings are in question. Jobs that leave the queue but never come out on paper mean the Mac handed them over successfully – the problem is inside the printer.

    Why macOS pauses printers
    


    When a job fails – the printer was off, out of paper or briefly unreachable – macOS pauses the printer’s queue so it doesn’t keep throwing documents at a printer that can’t take them. The catch: it stays paused after the printer is fine again. Many “my Mac won’t print” problems end with one click on Resume.
    

    If the queue pauses again immediately, the job at the top is probably the problem. Delete it and print the document again. If even a fresh, simple document pauses the queue, the diagnosis moves on to the printer display and the network.
    

    The iPhone comparison
    


    If you have an iPhone or iPad on the same Wi-Fi, use it as a test instrument. Open a photo or web page, tap Share, then Print. AirPrint printers appear without any setup. If the iPhone prints, the printer and network work and the fault is in the Mac’s printer entry – removing and re-adding the printer usually fixes it. If the iPhone can’t find or use the printer either, the Mac is cleared and the printer’s Wi-Fi or the router comes next.

    Removing and adding the printer the right way
    


    Removing a printer and adding it again makes the Mac discover it fresh at its current network address. In macOS 13 Ventura or laterSystem Settings > Printers & Scanners, select the printer and remove it (in newer versions with “Remove Printer…”, in older ones with the minus button). Then add it again (“Add Printer, Scanner or Fax…” or the plus button).
    

    The add dialog has a menu labeled “Use”. For most current printers it offers AirPrint (sometimes as “Secure AirPrint”), which needs no extra software. For some models it also offers a driver from the maker. If printing fails with one choice, remove the printer and add it with the other. AirPrint is often the more reliable choice for everyday printing; a maker’s driver can unlock features such as special paper types.
    

    Printer software for many models is delivered through macOS 13 Ventura or laterSystem Settings > General > Software Update. Install pending updates before you look for drivers elsewhere, and if you do need one, get it from the printer maker’s own support site.
    

    When neither Mac nor iPhone can print
    


    Then the shared parts are left: the printer’s Wi-Fi and the router. Restart in a set order – printer off, router restart, wait for internet, printer on, Mac restart – so that the printer rejoins a router that is already running. If that doesn’t help, print the printer’s network configuration report from its control panel. It shows which network the printer is on and which address it has. A missing address or a different network name means the printer has to be reconnected from its own panel or the maker’s app.
    

    If the printer disappears after every router restart, reserve its address in the router (often under “DHCP reservation” or “address reservation”). That is a router setting and can be removed again at any time.
    

    Reset printing system: the last resort
    


    macOS can reset its entire printing system: Control-click (or right-click) in the empty part of the printer list in Printers & Scanners and choose “Reset printing system”. It removes every printer, every waiting job and the saved printer presets. Afterwards you add each printer again. It can help when one printer stays broken even after removing and re-adding it, but it is never the first step – and on a shared Mac it affects every user’s printers.
    

    Before a reset, note what you have.
    Write down each printer’s name and whether it was added as AirPrint or with a maker’s driver, so you can set them up the same way afterwards.
    

    Stay clear of “printer fix” software and support numbers found through ads. Apple’s own documentation and the printer maker’s support site cover every step on this page.
    


    Questions people ask
    Why does my Mac say the printer is paused?
    macOS pauses a printer’s queue after a job fails, for example because the printer was off or out of paper. It stays paused until you click Resume in the queue window, even after the printer is fine again.
    What is AirPrint and do I need a driver?
    AirPrint is Apple’s driverless printing standard, supported by most current printers. With AirPrint you don’t need extra software. Some printers also offer a model-specific driver, which you can choose when adding the printer.
    What does “Reset printing system” delete?
    All printers, all waiting print jobs and printer presets on that Mac. It doesn’t delete documents. Afterwards you add your printers again.
