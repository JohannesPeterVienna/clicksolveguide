    What “connected, no internet” actually means
    


    Being connected to Wi-Fi and being connected to the internet are two different things. The Wi-Fi icon only reports the short radio link between your device and the router. Behind the router there are three more stages: the line to your internet provider, the provider’s network including its DNS servers, and finally the website or app you want to use. Any of them can fail while the bars stay full.
    

    Operating systems notice this with a small test of their own. Shortly after joining a network, Windows, macOS, iOS and Android each try to fetch a tiny file from a test address of their maker. If that doesn’t work, you see “No internet, secured” on Windows, “No Internet Connection” under the network name on iPhone, or “Connected, no internet” or “Connected without internet” on Android. The message is a symptom, not a diagnosis: it says something between router and test server is broken, not what.
    

    That’s why the diagnosis above starts with the question that removes the most suspects at once – do other devices on the same Wi-Fi work? – and only then looks at your device in detail.

    Why the order of the checks matters
    


    Most fix lists start with the heaviest tools: reset the network settings, reinstall the driver, reset the router. Those steps erase saved passwords and settings, and they are pointless if the problem is an outage at your provider. The diagnosis on this page does the opposite. It begins with checks that change nothing and rule out whole layers:
    

    • Does everything fail, or only one site? If other sites work, your connection is fine and the problem is the site or app. That clears four layers with one look.
      • 

    • Public or guest network? Hotels, cafés and trains hold all traffic until you accept their terms on a sign-in page – the most common reason for “connected, no internet” away from home.
      • 

    • Do other devices work on the same Wi-Fi? If yes, router and provider are fine and only your device remains. If no, your device is cleared and the router or provider is next.
    

    Only after those checks does the tree get specific: an address test for the device, the router’s internet light and a restart in the right order, a cable test that bypasses Wi-Fi, and finally the provider’s status page. Each answer is recorded in the fix log so you don’t have to remember what you already tried.

    When “No internet” is a false alarm
    


    Occasionally the message is wrong: pages load fine, but Windows still shows “No internet”. That happens when the operating system’s own test address is blocked – by a strict company firewall, a home ad-blocking DNS filter, or a VPN that routes traffic in an unusual way. Windows uses a Microsoft test site for this check, Apple devices use one of Apple’s, and Android uses one of Google’s. If everything you use works, you can ignore the icon; if some apps refuse to sync because they trust the icon, ask whoever runs the filter to allow the test address.
    

    The opposite also exists: the icon looks fine and the system test succeeds, but a single app fails. That is a service problem, not a Wi-Fi one, and the one-website diagnosis is the better starting point.
    

    Three commands that show where it stops
    


    On a Windows PC or a Mac you can look a little deeper than the icon. These three commands only read information; none of them changes a setting. Choose your system in the switcher above the layer map and only the matching commands are shown. Open Terminal on a Mac via macOS 13 Ventura or laterFinder > Applications > Utilities > Terminal, or on Windows right-click Start and choose Windows 11Terminal.
    

    Windows · Command Prompt or Terminal
    

    ipconfig
    

    What it does: shows the address your PC got from the router (IPv4 Address) and the router’s own address (Default Gateway).
    What it does not do: change or renew anything.
    

    macOS · Terminal
    

    networksetup -getinfo Wi-Fi
    

    What it does: shows the Mac’s Wi-Fi address and the router address.
    What it does not do: change any network setting.
    

    Windows · Command Prompt or Terminal
    

    ping -n 4 1.1.1.1
    

    What it does: sends four test packets to a public server by its number; replies prove that the route through router and provider works.
    What it does not do: test name lookup (DNS). Some networks block ping, so a timeout alone is not proof.
    

    macOS · Terminal
    

    ping -c 4 1.1.1.1
    

    What it does: sends four test packets by number and stops.
    What it does not do: test DNS or change anything.
    

    Windows · Command Prompt or Terminal
    

    nslookup example.com
    

    What it does: asks your DNS server for the address of a name.
    What it does not do: contact the website itself.
    

    On iPhone, iPad and Android there is no built-in command line; the diagnosis uses the menu paths instead.
    

    Read the results like this: an address starting with 169.254 means the router never answered; replies to the number test but a failing name test mean DNS; no replies to anything with a normal address point to the router or provider.
    

    What not to do while the internet is down
    


    Three things make a connection problem worse, and they are surprisingly common:
    

    • Don’t press the router’s recessed Reset button. A restart means unplugging the power. The pinhole Reset button restores factory settings: your Wi-Fi name and password change back to those on the label, and on some provider connections the router then can’t log in to the internet at all until it is set up again.
      • 

    • Don’t install “network repair” or “optimizer” tools. Windows, macOS, iOS and Android already include everything needed for these checks. Third-party repair tools add a new layer of software that can break networking further – and fake ones are a known malware route.
      • 

    • Don’t call numbers from search ads or pop-ups. Your provider’s real number is on your contract, bill or its official website. A pop-up claiming your connection is “infected” is a scam, as our scam guide explains.
    

    When it’s time to contact your provider
    


    If every device fails, the router has been restarted properly, and a cable connection fails too, the problem is almost certainly outside your home – the line, the provider’s equipment or an outage. Before you call, download the fix log from the diagnosis. It shows the support agent that you have already restarted the router, tested more than one device and checked the internet light, which usually lets them skip the first scripted steps and check your line directly.
    

    Note the router’s model and the color of its lights. If the provider supplied the router, ask whether they can see it online from their side; many providers can check and restart their own equipment remotely. If they arrange a technician visit, keep the fix log – it documents when the problem started and what was ruled out.
    


    Questions people ask
    Why does my phone work but my laptop says no internet?
    If the phone is on the same Wi-Fi with mobile data switched off, the router and provider are working. The problem is on the laptop: a stuck connection, an outdated saved network, a VPN or proxy, or its Wi-Fi driver. The diagnosis follows that branch once you answer “Yes – other devices work”.
    What does an IP address starting with 169.254 mean?
    Devices give themselves a 169.254 address when they ask the router for an address and get no answer. The device is joined to the Wi-Fi radio but not properly to the network. Rejoining the network, checking the router for a device block and restarting the router are the usual fixes.
    Will restarting the router delete my settings?
    No. Unplugging the power and plugging it back in keeps all settings. Only the small recessed Reset button, held for several seconds, restores factory settings – avoid it unless your provider tells you to use it.
    Is “No internet, secured” a security problem?
    No. “Secured” only means the Wi-Fi is password-protected and encrypted. “No internet” means Windows’ connectivity test failed. It says nothing about viruses or hacking.
    How long should I wait after restarting the router?
    Give it two to five minutes. The modem first has to synchronize with the provider’s line, then the router logs in and starts its Wi-Fi. Testing too early makes a working restart look like a failure.
