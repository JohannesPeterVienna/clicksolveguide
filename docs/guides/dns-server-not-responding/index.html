DNS server not responding: a plain-English fix

Windows Network Diagnostics sometimes ends with “Your computer appears to be correctly configured, but the device or resource (DNS server) is not responding.” Translated: your device asked for a website’s address and nobody answered. Here’s how to find out who should have.

Reviewed November 2, 2026Applies to: Windows 11, Windows 10, macOSSources: Microsoft Learn, Microsoft Support, Apple SupportPublisher: AdStern, Vienna

What DNS is, and what “not responding” means

Computers find websites by number, people by name. The Domain Name System (DNS) is the service that translates one into the other. Every time you open a site, your device asks a DNS server: “what is the address of example.com?” In most homes the router hands out its own address as the DNS server and forwards the questions to servers run by your internet provider.

“Not responding” means the question went out and no answer came back in time. The website was never contacted. That is useful information: it narrows the problem to the path between your device and the DNS server – the router, the provider’s DNS servers, or something on your device that redirects DNS, such as a VPN or a manually entered DNS address that no longer works.

Pick the system you are fixing.

Quick checks that change nothing

01

Compare with another device and with mobile data

Harmlessabout 2 min

Open a site you rarely visit on a phone connected to the same Wi-Fi, then on the same phone with Wi-Fi switched off. If both fail on Wi-Fi but mobile data works, your network’s DNS (router or provider) is the suspect.

02

Restart the router the right way

Harmlessabout 5 min

Unplug it, wait 30 seconds, plug it in and give it two to five minutes. A router’s DNS forwarder can hang while everything else looks normal. See how to restart a router for the order with separate modems.

Confirm it with two commands

These commands only read information. The first checks whether the internet works by number, without DNS. The second asks DNS directly.

Windows · Command Prompt or Terminal
ping -n 4 1.1.1.1

What it does: sends four test packets to a public server by its number. Replies mean the connection works and only names fail.

What it does not do: use DNS at all, or change anything.

macOS · Terminal
ping -c 4 1.1.1.1

What it does: sends four test packets by number and stops.

What it does not do: use DNS or change anything.

Windows · Command Prompt or Terminal
nslookup example.com

What it does: asks your current DNS server for the address. “DNS request timed out” confirms the server isn’t answering; the first lines show which server was asked.

What it does not do: change your DNS server.

macOS · Terminal
nslookup example.com

What it does: asks your current DNS server and shows which server answered (or didn’t).

What it does not do: change anything on the Mac.

Windows · Command Prompt or Terminal
ipconfig /flushdns

What it does: clears Windows’ list of remembered lookups – useful after the DNS problem is fixed, so old failures aren’t reused.

What it does not do: change DNS servers or network settings.

If the number test fails too, the problem isn’t DNS but the whole connection – continue with the Wi-Fi diagnosis.

Testing another DNS server – with an undo

If your network’s DNS is the suspect, you can point this one device at a public DNS service for a test. Widely used free resolvers include Cloudflare (1.1.1.1 and 1.0.0.1), Google Public DNS (8.8.8.8 and 8.8.4.4) and Quad9 (9.9.9.9). Each has its own privacy policy; read it if you plan to keep the setting.

03

Enter a public DNS server on this device

Admin neededabout 5 min

Open Windows 11Settings > Network & internet > Wi-Fi > (your network) properties > DNS server assignment > Edit. Write down what is there now. On Windows (administrator approval may be requested), switch to Manual, turn on IPv4 and enter a preferred and alternate server. On a Mac, add a server with the plus button.

Undo: Set DNS back to Automatic (DHCP) on Windows, or remove the added servers on the Mac with the minus button.

Don’t change DNS on networks that aren’t yours.

Company and school networks often require their own DNS for internal services and security filtering. A manual DNS setting can break those – and may break the same laptop on the next network you join.

If the site loads with the public server, you have confirmed that your provider’s DNS or the router’s forwarding is the problem. You can keep the setting on this device, change DNS in the router for all devices (if your router allows it), or report the fault to your provider.

What doesn’t help

Because DNS failures happen before any website is contacted, several popular tips miss the target: reinstalling the browser, clearing all browser data, or “resetting TCP/IP” as a first step. Commands like netsh winsock reset and netsh int ip reset exist and need administrator rights; they are only worth trying, as a last resort, when one Windows PC fails while everything else works and simpler steps haven’t helped – and afterwards Windows needs a restart. Download tools that promise to “fix DNS” are unnecessary and should be avoided.

Finally, remember the device-side causes: if this is the only device with the problem, check for a VPN, a security suite with web protection, or a manual DNS entry left over from an old network.

Scam protection: what this site never does

ClickSolve Guide never shows a phone number, never offers remote access and never recommends “PC optimizer”, “driver updater” or “cleaner” tools. If a pop-up says your device is infected and gives a number to call, it is a scam: close the browser tab (or the whole browser), don’t call, and don’t let anyone connect to your computer. Real error messages from Microsoft, Apple and Google do not ask you to phone anyone. How to spot fake support pop-ups.

Questions people ask

Is “DNS server not responding” dangerous?

No. It means name lookups are failing. Nothing is infected and no data is exposed. It is a connection problem, usually at the router or the provider.

Should I switch to 1.1.1.1 or 8.8.8.8 permanently?

You can, on your own devices or router, if the provider’s DNS keeps failing. Read the service’s privacy policy first, and leave DNS on automatic for company or school devices.

Do I need administrator rights to change DNS?

On Windows, changing a network’s DNS setting can ask for administrator approval on managed or standard accounts. On a Mac, network settings may ask for an administrator password.
