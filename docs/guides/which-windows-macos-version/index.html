How to tell which Windows or macOS version you have

Menu paths, support articles and update advice all depend on your exact version. Here is where each system shows it, the two commands that answer it instantly, and what your browser reports right now.

Reviewed November 2, 2026Applies to: Windows 11, Windows 10, macOS, iPhone/iPad, AndroidSources: Microsoft Support, Microsoft Learn, Apple Support, Android HelpPublisher: AdStern, Vienna

Why the exact version matters

Windows 11 moved many settings compared with Windows 10, and macOS replaced System Preferences with a redesigned System Settings in macOS 13 Ventura. A guide written for one version can send you looking for a button that doesn’t exist on the other. Support staff will also ask for your version early on, and whether a system still gets security updates depends on it.

The version has two parts worth noting: the name or number (Windows 11, macOS Sonoma, iOS 18) and, on Windows, the release such as 23H2 or 24H2 plus a build number. For most troubleshooting the first part is enough; for reporting a bug, give both.

For support requests, the hardware model is often just as useful as the system version. Windows shows the device name and processor on the same About page; the exact model is printed on a label underneath most laptops or in the PC maker’s own support app. On a Mac, About This Mac names the model and year, for example “MacBook Air (M2, 2022)”. iPhones list the model name under Settings > General > About. Note both – model and version – in the fix log of any diagnosis, and support can skip the first round of questions.

A quick visual hint for Windows: Windows 11 centers the Start button on the taskbar by default and uses rounded window corners; Windows 10 has Start at the far left. The taskbar can be moved, so treat that as a hint and confirm in Settings.

Why websites often guess wrong

Browsers send a “user-agent string” with every request, and many websites read the operating system from it. But browser makers froze parts of that string for privacy and compatibility. Windows 11 still reports itself as “Windows NT 10.0”, exactly like Windows 10. Safari and Chrome on current Macs report a fixed old macOS version number. An iPad asking for desktop pages pretends to be a Mac.

Chromium-based browsers such as Chrome and Edge offer a newer mechanism called User-Agent Client Hints. A site can ask for the “platform version”; on Windows, Microsoft documents that values of 13 and above mean Windows 11 and values from 1 to 10 mean Windows 10. That is what the box above uses when your browser supports it. ClickSolve Guide uses the same logic to suggest a version in its switchers – and always lets you correct it.

Two commands that answer it instantly

Windows · Command Prompt or Terminal
winver

What it does: opens a small “About Windows” window with the version (e.g. 24H2) and OS build. Type it into the Start menu search or the Run box (Windows key + R).

What it does not do: change anything or need administrator rights.

macOS · Terminal
sw_vers

What it does: prints the product name, the macOS version number and the build in Terminal.

What it does not do: change anything or need a password.

On iPhone, iPad and Android, use the About page in Settings shown above.

The macOS version number maps to a name: 13 is Ventura, 14 is Sonoma and 15 is Sequoia; macOS 12 is Monterey and 11 is Big Sur. Apple names each yearly release, and About This Mac shows both the name and the number.

Is your version still supported?

Microsoft ended support for Windows 10 on October 14, 2025: since then, regular Windows 10 installations no longer get security updates. Paid Extended Security Updates were available for a limited time. Windows 11 versions are supported for a fixed period after release; Settings > Windows Update shows when a newer version is available.

Apple doesn’t publish fixed end dates for macOS, but in practice security updates focus on the current release and the previous ones. If Software Update no longer offers anything for your Mac, it may be too old for current macOS versions. For phones, the maker decides how long updates come – check the About page and the maker’s official support site.

Pop-ups about “expired” systems can be fake.

Real update notices appear in Windows Update or Software Update, not as browser pop-ups with phone numbers. See our scam guide.

Scam protection: what this site never does

ClickSolve Guide never shows a phone number, never offers remote access and never recommends “PC optimizer”, “driver updater” or “cleaner” tools. If a pop-up says your device is infected and gives a number to call, it is a scam: close the browser tab (or the whole browser), don’t call, and don’t let anyone connect to your computer. Real error messages from Microsoft, Apple and Google do not ask you to phone anyone. How to spot fake support pop-ups.

Questions people ask

How do I know if I have Windows 10 or 11?

Open Settings > System > About, or type winver into the Start search. The edition line says Windows 10 or Windows 11.

Why does a website think my Windows 11 PC is Windows 10?

Browsers report “Windows NT 10.0” for both. Only Chromium browsers can reveal the difference through Client Hints, and only when a site asks for it.

What macOS version do I have?

Choose Apple menu > About This Mac. You see the name (such as Sonoma) and the version number. In Terminal, sw_vers prints the same.

Is it safe to keep using Windows 10?

Without security updates, the risk grows over time. Microsoft ended regular support in October 2025; upgrading to Windows 11 (if the PC qualifies) or replacing the PC keeps you protected.
