Android says “Connected, no internet”

Android shows “Connected, no internet” when it has joined a Wi-Fi network but its own internet test fails. The cause can be the network – or one setting on the phone that many people never knew they had changed.

What the phone is telling you

After joining a Wi-Fi network, Android quietly tries to reach a test address on Google’s servers. If the reply arrives, the network gets the normal Wi-Fi icon. If it doesn’t, Android marks the network “Connected, no internet” or “Connected without internet”, depending on the phone maker and version, and may switch to mobile data in the background so apps keep working.

So the message means: the link to the router works, but something between the router and the internet – or in the phone’s own name lookup – does not. Android menus differ between manufacturers. The paths below use the wording of Google’s Pixel phones and add Samsung’s where it differs; on other brands look for the same words.

Checks that change nothing

01

Check other devices on the same Wi-Fi

Harmlessabout 1 min

If a laptop or another phone works on the same network, the router and provider are fine and the problem is on this phone. If nothing works, restart the router first; the Wi-Fi diagnosis covers that path in detail.

02

Look for “Sign in to network”

Harmlessabout 1 min

On hotel, café or guest networks, Android shows a notification such as “Sign in to Wi-Fi network”. Tap it and accept the terms. Until then, the network has no internet for you.

03

Switch Wi-Fi off and on, then restart the phone

Harmlessabout 2 min

Use AndroidSettings > Network & internet > Internet > Wi-Fi switch (Samsung: Settings > Connections > Wi-Fi). A restart also clears a stuck network service.

Private DNS: the hidden culprit

Android has a setting called Private DNS that sends all name lookups, encrypted, to a DNS provider of your choice. The default, “Automatic”, uses encryption when the network’s DNS server supports it and falls back otherwise. But if someone entered a specific provider hostname – perhaps following an ad-blocking tip – and that hostname is mistyped, no longer exists or is blocked on this network, every lookup fails. Android then reports “no internet” on Wi-Fi, and often on mobile data too.

04

Set Private DNS to Automatic for a test

Changes a settingabout 2 min

Open AndroidSettings > Network & internet > Private DNS (Samsung: Settings > Connections > More connection settings > Private DNS). If a hostname is entered, write it down and switch to Automatic. Test again.

Undo: Select “Private DNS provider hostname” again and re-enter the hostname you wrote down.

Date, time and the network profile

05

Set date and time automatically

Changes a settingabout 1 min

A wrong clock breaks encrypted connections, including the ones Android uses for its own checks. Use AndroidSettings > System > Date & time > Set time automatically (Samsung: Settings > General management > Date and time > Automatic date and time).

Undo: Switch automatic time off and set the time manually again.

06

Forget the network and join again

Changes a settingabout 3 min

Tap the gear next to the network in AndroidSettings > Network & internet > Internet (Samsung: Settings > Connections > Wi-Fi) and choose Forget. Join again with the password. On the network’s details page you will also find the privacy option (“Use randomized MAC” or similar) – routers with a device filter may block a randomized address.

Undo: Join the network again with its password; switch the MAC option back if you changed it.

07

Disconnect VPN and ad-blocking apps

Changes a settingabout 2 min

VPN apps and some ad blockers route all traffic through themselves. Pause them in their app or in AndroidSettings > Network & internet > VPN (Samsung: Settings > Connections > More connection settings > VPN). If “Always-on VPN” is switched on together with “Block connections without VPN”, Android lets no traffic through while that VPN can’t connect; with Always-on VPN alone, apps fall back to the normal connection. Both switches sit in the VPN app’s settings (gear icon) in that menu.

Undo: Reconnect the VPN in its app.

Last resort: reset network settings

08

Reset Wi-Fi, mobile and Bluetooth settings

Last resortabout 10 min

AndroidSettings > System > Reset options > Reset Wi-Fi, mobile & Bluetooth (Samsung: Settings > General management > Reset > Reset network settings) removes all saved Wi-Fi networks, Bluetooth pairings and mobile network settings you changed. Your apps, photos and files stay. Don’t confuse it with the factory reset in the same menu.

Undo: No undo: join Wi-Fi networks and pair Bluetooth devices again.

Two resets live next to each other.

The network reset is harmless to your data. “Erase all data (factory reset)” wipes the phone – read the option name twice.

If the phone still fails on every Wi-Fi network while other devices work, check for a system update and contact the phone maker’s support through its official website.

When the message is wrong

Sometimes browsing works perfectly while Android insists there is no internet. That happens when the network blocks Google’s test address – some company networks, filtering DNS services and home ad-blocking setups do. Android may then prefer mobile data and use up your data plan. If you run the filter, allow Google’s connectivity check; otherwise, ask the network owner. On a network you trust, Android may also offer to stay connected anyway when you tap the network.

Questions people ask

Why does my Android say connected without internet?

It joined the Wi-Fi but its internet test failed. Common causes: the router or provider is down, a sign-in page is waiting, Private DNS is set to a broken hostname, or a VPN can’t connect.

What is Private DNS and should I use it?

It encrypts your name lookups. “Automatic” is a sensible default. A specific provider hostname works only if it is typed correctly and not blocked on the network.

Does resetting network settings delete my photos?

No. It deletes saved Wi-Fi networks, Bluetooth pairings and mobile network settings. The factory reset, a separate option, is the one that erases data.

Why does my phone use mobile data on Wi-Fi?

When Android thinks a Wi-Fi network has no internet, it may switch to mobile data so apps keep working. Fix the Wi-Fi problem, or turn off the switching feature in the Wi-Fi or connection preferences if you prefer.

Are Samsung menus different?

Yes. Samsung uses “Connections” instead of “Network & internet” and “General management” for reset and date options. The guide lists both.
