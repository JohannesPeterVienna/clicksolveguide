Guides

Some problems are better explained than branched: what a message means, what is safe to try in which order, and when to stop and get help.

Each guide states which systems it applies to, when it was last reviewed and which official documentation it is based on. Menu paths follow the version switcher, so Windows 10 users don't read Windows 11 menus and the other way round. Commands come with a copy button and a sentence on what they do – and what they don't do – so you never paste something you don't understand.

The guides deliberately avoid third-party “repair” tools. When software is needed, it comes from the operating system itself or from the device maker's official website. The tech support scam guide explains why: fake support pages and pop-ups are one of the most common ways people lose money while trying to fix a computer.

Looking for an interactive check instead? The diagnoses ask questions and narrow the cause down for you.

Which guide to read when

Each guide answers one situation. If you are not sure which one is yours, the short notes below say what each guide starts from and what it leaves to another page.

DNS server not responding: a plain-English fix

Read this when Windows Network Diagnostics reports that the DNS server isn’t responding, or when sites fail by name while the connection itself looks fine. It shows how to confirm the diagnosis with ping and nslookup, and how to try another DNS server for a test – with the steps to set it back to automatic.

Windows Update stuck: safe steps before you restart

Read this when an update sits at the same percentage or on “Working on updates” for a long time. A decision table separates the cases where waiting is right from those where a restart is safe, and resetting the update cache is kept for the very end.

Mac running slow: check these five things first

Read this when a Mac shows the spinning wheel, apps open slowly or the fan runs loud. It checks five causes in Activity Monitor and System Settings – background indexing after an update, storage, a runaway app, memory pressure and login items – without any cleaner app.

Bluetooth not working on Windows 11

Read this when the Bluetooth switch is missing in Windows 11, a device won’t pair, or a paired mouse or headset keeps dropping out. It works from the switch and the adapter up to the device itself, with Windows 10 paths in the version switcher.

How to restart a router the right way

Read this before you unplug anything: the order for modem and router, how long to wait, what the lights usually mean afterwards, and why the pinhole reset button is not a restart. Several diagnosis and guide pages link here for their router step.

How to tell which Windows or macOS version you have

Read this when a support article or a menu path depends on your exact system version. It shows where Windows, macOS, iOS and Android display it, two commands that answer it instantly, and why websites often guess the version wrong.

Tech support scams: how to spot fake pop-ups and phone numbers

Read this when a pop-up claims your device is infected, someone calls about “errors” on your computer, or you have already let a caller connect remotely. It explains the pattern, how to close a pop-up that won’t go away, and what to do in which order if money or access is involved.

iPhone won’t connect to Wi-Fi

Read this when an iPhone or iPad rejects the Wi-Fi password, doesn’t list the network or shows “No Internet Connection” under its name. It starts from the small text under the network name and keeps Reset Network Settings as the last resort.

Android says “Connected, no internet”

Read this when an Android phone shows “Connected, no internet” or “Connected without internet”. It checks sign-in pages, Private DNS, date and time and the router in that order, with Samsung Galaxy menu names where they differ.
