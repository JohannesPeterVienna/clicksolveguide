Windows Update stuck: safe steps before you restart

A Windows update that seems frozen is usually still working – and switching off at the wrong moment is the one thing that can turn a slow update into a broken installation. This guide separates the moments when waiting is right from the ones when a restart is safe.

Reviewed November 3, 2026Applies to: Windows 11, Windows 10Sources: Microsoft Support – Windows Update troubleshootingPublisher: AdStern, Vienna

Where exactly is it stuck?

“Stuck” can mean three very different situations. If the update hangs in the Settings app – downloading or installing at some percentage while Windows runs normally – nothing critical is happening yet. You can keep working, restart normally, or retry. If the PC is in the middle of a restart, showing a blue screen with “Working on updates” and “Don’t turn off your PC”, Windows is replacing system files, and cutting the power can leave it unable to start. If the screen says it is undoing changes, Windows is rolling back a failed update – also a moment to wait.

Large updates can take a long time on older PCs, particularly those with a spinning hard disk instead of an SSD, and the percentage often stands still for long stretches while work continues underneath. The decision guide below helps you judge it.

Many laptops and PCs have a drive activity light; on others, Task Manager (Ctrl + Shift + Esc) shows disk and CPU activity while Windows is still usable. Activity means work is going on, even if the screen doesn’t move.

Safe steps while Windows still runs

01

Check the internet connection and free space

Harmlessabout 5 min

A download that never moves often has no working connection – test a website. Updates also need free disk space; look at Windows 11Settings > System > Storage. If the system drive is nearly full, empty the Recycle Bin and remove large files you don’t need.

02

Restart normally and try again

Harmlessabout 15 min

When the update is stuck in Settings (not during a restart), a normal restart from the Start menu is safe. Then open Windows 11Settings > Windows Update > Check for updates.

03

Run Windows’ own troubleshooter

Harmlessabout 10 min

Windows includes an update troubleshooter. On Windows 11 it is under Windows 11Settings > System > Troubleshoot > Other troubleshooters > Windows Update; on newer builds Windows may open it in the Get Help app. It checks the update components and repairs what it can.

04

Pause updates for a short while

Changes a settingabout 1 min

If you need the PC right now, pause updates in Windows 11Settings > Windows Update > Pause updates and continue later, for example overnight on power.

Undo: Click Resume updates on the same page.

If it hangs during the restart

When the screen says “Working on updates” or “Don’t turn off your PC”, the safest course is patience. Keep a laptop plugged in. If you are unsure, leave it for several hours or overnight – a slow update finishing at 3 a.m. is better than a forced power-off in the middle of replacing system files.

If the screen has not changed for many hours and there is no drive activity at all, a hard power-off (holding the power button for about ten seconds) becomes the remaining option. Windows usually detects the interrupted update at the next start and rolls it back. If it doesn’t start properly, it typically offers Automatic Repair and the recovery options; Microsoft Support documents these in its recovery articles.

Back up before big updates.

Large feature updates are the ones most likely to take long. A current backup of your personal files makes any outcome recoverable.

Last resort: resetting the update cache

If the same update keeps failing and the troubleshooter didn’t help, Windows’ download cache may be damaged. The documented fix is to stop the update services, rename the cache folder so Windows creates a fresh one, and start the services again. This needs a Command Prompt opened with “Run as administrator”. Run the lines one by one and read the answer after each:

Windows · Command Prompt (Run as administrator)Admin needed
net stop wuauserv

What it does: stops the Windows Update service. Windows answers that the service was stopped – or that it is not started, which is fine too: then it was already stopped.

What it does not do: uninstall anything; Windows starts the service again later.

Windows · Command Prompt (Run as administrator)Admin needed
net stop bits

What it does: stops the Background Intelligent Transfer Service, which downloads updates. Run it on its own line even if the first command said the service was not started – “is not started” here also just means it is already stopped.

What it does not do: uninstall anything; Windows starts the service again later.

Windows · Command Prompt (Run as administrator)
dir C:\Windows\SoftwareDistribution.old

What it does: checks whether a SoftwareDistribution.old folder is left over from an earlier attempt. “File Not Found” means you can go on. If the folder exists, the rename below would fail: delete that old folder first (rd /s /q C:\Windows\SoftwareDistribution.old) or rename the new one to SoftwareDistribution.old2 instead.

What it does not do: change anything – it only lists the folder.

Windows · Command Prompt (Run as administrator)Admin needed
ren C:\Windows\SoftwareDistribution SoftwareDistribution.old

What it does: renames the update download folder, so Windows builds a new, empty one. Downloaded updates will be fetched again.

What it does not do: delete installed updates or your files. If it says access denied, a service is still running – run both stop commands again, or restart the PC and start again from the first line.

Windows · Command Prompt (Run as administrator)Admin needed
net start bits

What it does: starts the download service again.

What it does not do: install updates by itself.

Windows · Command Prompt (Run as administrator)Admin needed
net start wuauserv

What it does: starts the Windows Update service again.

What it does not do: install updates by itself – go to Windows Update and click Check for updates.

The commands are separate on purpose: chained with “&&”, the second one is skipped as soon as the first reports an error – and “service is not started” counts as one, so BITS would keep running.

To undo: once updates install again you can delete the SoftwareDistribution.old folder; if you want to reverse the change before that, stop the services, delete the new SoftwareDistribution folder and rename the .old folder back.

What to avoid

Don’t install third-party “update fixers” or registry cleaners. Windows Update is repaired with Windows’ own tools, and fake fix tools are a common way to get malware. Don’t follow advice to delete random folders in C:\Windows. And if a pop-up or a call claims your updates have failed and offers to fix them remotely for a fee, it is a scam – Microsoft doesn’t call people about updates. More in our guide to tech support scams.

Questions people ask

Does Windows Update need a lot of free space?

Feature updates need several gigabytes free on the system drive. Settings > System > Storage shows how much is free; Windows usually reports when there is not enough space.

How long should I wait if Windows Update is stuck?

If the PC is restarting and shows “Working on updates”, give it several hours, or overnight, as long as there is drive activity. In the Settings app, a normal restart is safe if nothing moves for an hour or two.

Can I turn off my PC during an update?

Avoid it while the screen says “Working on updates” or “Don’t turn off your PC”. Windows is replacing system files then. A hard power-off is a last resort after many hours without any activity.

Is deleting the SoftwareDistribution folder safe?

Renaming it, with the update services stopped, is a documented repair step. It removes downloaded update files, not installed updates or your data, and Windows downloads what it needs again.

Why does Windows Update keep failing?

Common reasons are too little free space, an unstable connection, a damaged download cache or a driver that conflicts with the update. Note the error code shown in Windows Update; it is the best search term on Microsoft’s support site.

Does pausing updates leave me unprotected?

For a short time, yes – security fixes are delayed. Pause only as long as needed and resume updates as soon as you can.
