Reference · Windows 11, Windows 10, macOS

Windows build numbers and macOS versions

Support articles say “Windows 11, version 24H2”; your PC says “OS Build 26100.4946”. A Mac says “15.6”; the article says “Sequoia”. This page translates between the two, using the release tables Microsoft and Apple publish, and tells you whether Microsoft still lists your Windows version for updates.

Reading the build number

Press the Windows key and R, type winver and press Enter. The window shows a version such as 24H2 and an OS build such as 26100.4946. The part before the dot identifies the version – it is what the table below is sorted by. The part after the dot rises with every monthly update. If it is lower than the “latest build” in the table, updates are waiting to be installed; the lookup compares the two for you.

On this site, menu paths are written for “Windows 11” and “Windows 10”. Any build from 22000 upward is Windows 11; builds from 10240 to 19045 are Windows 10.

The dates are Microsoft’s, as published on the retrieval date; Microsoft changes them from time to time. “End of updates” is the day after which that version gets no more security updates for the named editions.

Sources and how this page was made

Version names, build numbers and dates – facts, no prose – were extracted by a script from the tables and headings of the Microsoft and Apple pages below. The split into “Windows 11” and “Windows 10” menu paths and the third column of the macOS table are ClickSolve Guide’s own.

  • Microsoft Learn – Windows 11 release information – retrieved November 18, 2026; the page states its own last update as 2026-11-13.
  • Microsoft Learn – Windows 10 release information – retrieved November 18, 2026; the page states its own last update as 2026-11-13.
  • Apple Support – Find out which macOS your Mac is using – retrieved November 18, 2026; the page states its own last update as November 09, 2026.

Found a difference to the source? Tell us – the table is rebuilt from the source and the retrieval date changes.
