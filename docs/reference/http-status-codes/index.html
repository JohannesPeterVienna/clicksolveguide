HTTP status codes: who has to fix what

“404”, “403 Forbidden”, “502 Bad Gateway”: a three-digit status code is the web server’s own answer. That is the most useful thing about it – a page that shows one has proved that your device, Wi-Fi, router, provider and DNS work. This page lists all 62 codes in the official IANA registry and says, for the ones a browser shows, on which side the fix is.

Reading a status code as a diagnosis

A status code can only appear when a connection to the server exists. If you see a browser-made page instead – “This site can’t be reached”, “Server not found” – there was no answer at all, and the browser’s own error code is the thing to read.

The registry gives each code a name and the document that defines it. The column “What it tells you” is this site’s summary of that definition from the visitor’s point of view; codes without their own note get the note for their class. Whether a 403 or 429 is “your fault” is often unknowable from outside – the note says what you can try.
