Windows Update error codes: meaning and next safe step

Windows Update reports failures as codes like 0x80070422. Microsoft documents several hundred of them for administrators. This page picks 39 that turn up on home PCs, says in plain words what each one means and names the next step that is safe to take – with a link to Microsoft’s own page for every code. The lookup also recognises the other 249 codes in Microsoft’s lists and sends you to the right Microsoft page.

What a code can and cannot tell you

A Windows Update code names what gave up: the connection to the update server, a download, the installation, Windows’ own store of system files, or – for the codes starting with 0xC19 – the upgrade to a new Windows version. That is enough to choose the right first step and to describe the fault precisely if you ask for help. It rarely names the one cause.

The steps below never go beyond what Windows itself offers. They follow the order of our guide Windows Update stuck – wait, restart, free space, Windows’ own troubleshooter, and only at the end the reset of the update cache, with its undo. Where Microsoft’s remedy is a command for administrators, the row says so and links to Microsoft instead of repeating it.

On a PC managed by a company or school, update settings and servers belong to IT; report the code there.

Code and official name are Microsoft’s; a dash means Microsoft gives no name. Meaning and next step are our own wording, based on the Microsoft page linked in the last column.

Sources and how this page was made

The selection of 39 codes is ours. A build script checks that every selected code is documented on one of the three Microsoft pages below and takes from them only the code and its official name. Microsoft’s descriptions and mitigation texts are not reproduced; “What it means” and “Next safe step” were written by ClickSolve Guide after reading them, and limited to steps a home user can take without extra tools. The steps were not tried by provoking each error on a test PC.
