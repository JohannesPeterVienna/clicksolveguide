Keyboard shortcuts for when something is stuck

Microsoft’s and Apple’s shortcut lists run to several hundred entries. When an app hangs, the screen stays black or a pop-up will not close, about two dozen of them matter. This page picks those 27 and says for each what it does and where in a diagnosis it saves time.

Data retrieved November 18, 2026Publisher: AdStern, Vienna

Why shortcuts belong in a diagnosis

A frozen app, a missing taskbar or a full-screen fake warning takes away the mouse’s targets. The keyboard still works in most of these cases, and the shortcuts below open exactly the system tools the diagnoses and guides on this site send you to: Task Manager, Settings, the Run box, Force Quit, the screenshot tools for the fix log.

The key combinations are the makers’ – a build script checks that each one is listed on Microsoft’s page (Windows 11 section) or Apple’s page. Both text columns are written by ClickSolve Guide; the makers’ full lists are linked under Sources.

Troubleshooting shortcuts for Windows 11 and macOS
SystemKeysWhat it doesWhen it helps
Windows 11Ctrl+Shift+EscOpens Task Manager directly.An app is frozen or the PC is slow: see what uses the processor and memory, and end a hung app.
Windows 11Windows key+IOpens the Settings app.The starting point of almost every Windows menu path on this site (“Settings > …”).
Windows 11Windows key+XOpens the menu you also get by right-clicking the Start button.Fast way to Device Manager, Terminal and other system tools when the Start menu is slow.
Windows 11Windows key+ROpens the Run box for typing a command.Runs short commands from the guides, such as winver for the version.
Windows 11Windows key+PauseOpens Settings on the System > About page.Shows the Windows edition and version without typing anything.
Windows 11Windows key+AOpens the quick settings panel at the right end of the taskbar.The panel with the Wi-Fi, Bluetooth and Airplane mode buttons – the first look in every Wi-Fi diagnosis.
Windows 11Windows key+Ctrl+Shift+BWakes the display when the screen is blank or black.Black screen while the PC is clearly running: try this before holding the power button.
Windows 11Windows key+LLocks the PC.Before you hand the device to someone or walk away during a long repair step.
Windows 11Windows key+Shift+SLets you mark an area of the screen and copies it as a picture.Capture the exact error message for your fix log instead of retyping it.
Windows 11Windows key+PrtScnSaves a picture of the whole screen as a file in Pictures > Screenshots.Useful when an error disappears quickly.
Windows 11Windows key+KOpens the Cast panel for wireless displays.A wireless display does not appear: this opens the list directly.
Windows 11Windows key+POpens the choice of display mode for a second screen.A second screen or projector stays dark: check whether the mode is “PC screen only”.
Windows 11Windows key+EOpens File Explorer.Reaches your files when the taskbar does not react.
Windows 11Alt+F4Closes the window in front.Closes a window that has no reachable close button, such as a full-screen scam pop-up.
Windows 11F5Reloads the window in front.After a fix, to see whether a page or folder now loads.
macOSOption-Command-EscOpens the Force Quit window.An app shows the spinning wheel: force quit that one app instead of restarting the Mac.
macOSCommand–Space barOpens Spotlight search.Opens Terminal, Activity Monitor or System Settings by typing the name.
macOSCommand-QQuits the app in front completely.Closing the window leaves most Mac apps running; this ends them. Also closes a browser stuck on a scam page.
macOSCommand-Comma (,)Opens the settings of the app in front.Quick way into the browser’s or mail app’s settings during a check.
macOSShift-Command-5Opens the screenshot and screen recording tool.Capture the exact error message for your fix log.
macOSControl-Command-QLocks the screen.Before you walk away during a long repair step.
macOSShift-Command-QLogs you out of your user account, after asking.Logging out and in again restarts your login items without restarting the Mac.
macOSControl–Command–Power buttonForces a restart without the chance to save – on keyboards without Touch ID.Last resort when nothing reacts: unsaved work is lost. Macs with Touch ID are handled differently – see Apple’s page.
macOSControl–Power buttonShows the dialog for restart, sleep or shut down – on keyboards without Touch ID.Restart from the keyboard when the pointer is stuck.
macOSShift-Command-UOpens the Utilities folder in the Finder.The folder that holds Terminal, Activity Monitor and Disk Utility.
macOSCommand-TabSwitches to the app you used before.Check which apps are open when one is hidden behind a full-screen window.
macOSCommand-POpens the print dialog.The starting point of the Mac printer diagnosis.
