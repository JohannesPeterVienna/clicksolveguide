Keyboard shortcuts for when something is stuck

Microsoft’s and Apple’s shortcut lists run to several hundred entries. When an app hangs, the screen stays black or a pop-up will not close, about two dozen of them matter. This page picks those 27, quotes what the maker says each one does and adds the situation in a diagnosis where it saves time.

Data retrieved November 18, 2026Publisher: AdStern, Vienna

Why shortcuts belong in a diagnosis

A frozen app, a missing taskbar or a full-screen fake warning takes away the mouse’s targets. The keyboard still works in most of these cases, and the shortcuts below open exactly the system tools the diagnoses and guides on this site send you to: Task Manager, Settings, the Run box, Force Quit, the screenshot tools for the fix log.

The key combinations and the descriptions are quoted from the makers’ pages. The Windows rows come from the Windows 11 section of Microsoft’s page. The column “When it helps” is this site’s own.

Troubleshooting shortcuts for Windows 11 and macOS
SystemKeysWhat the maker says it doesWhen it helps (our note)
Windows 11Ctrl+Shift+EscOpen Task Manager.An app is frozen or the PC is slow: see what uses the processor and memory, and end a hung app.
Windows 11Windows key+IOpen Settings.The starting point of almost every Windows menu path on this site (“Settings > …”).
Windows 11Windows key+XOpen the Quick Link menu. This shortcut is the same action as right-click on the Start menu.Fast way to Device Manager, Terminal and other system tools when the Start menu is slow.
Windows 11Windows key+ROpen the Run dialog box.Runs short commands from the guides, such as winver for the version.
Windows 11Windows key+PauseOpens the Settings app to the System > About page.Shows the Windows edition and version without typing anything.
Windows 11Windows key+AOpen the Windows 11 action center.The panel with the Wi-Fi, Bluetooth and Airplane mode buttons – the first look in every Wi-Fi diagnosis.
Windows 11Windows key+Ctrl+Shift+BWake up the device when the screen is blank or black.Black or blank screen while the PC is clearly running: try this before holding the power button.
Windows 11Windows key+LLock the computer.Before you hand the device to someone or walk away during a long repair step.
Windows 11Windows key+Shift+SSelect a region of the screen to capture a screenshot to the clipboard. You can then open the Snipping Tool to share or markup the image.Capture the exact error message for your fix log instead of retyping it.
Windows 11Windows key+PrtScnCapture a full screen screenshot and save it to a file in the Screenshots subfolder of the Pictures folder.Saves the whole screen as a file – useful when an error disappears quickly.
Windows 11Windows key+KOpen Cast from Quick Settings to connect to a display. For more information, see Screen mirroring and projecting to your PC or wireless display.Wireless display or speaker does not appear: this opens the list directly.
Windows 11Windows key+POpen project settings to choose a presentation display mode.A second screen or projector stays dark: check whether the mode is “PC screen only”.
Windows 11Windows key+EOpen File Explorer.Opens File Explorer when the taskbar does not react.
Windows 11Alt+F4Close the active window. If no windows are open, prompt to shutdown.Closes a window that has no reachable close button, such as a full-screen scam pop-up.
Windows 11F5Refresh the active window.Reloads a page or window after a fix, to see whether it worked.
macOSOption-Command-EscForce quit an app.An app shows the spinning wheel: force quit that one app instead of restarting the Mac.
macOSCommand–Space barShow or hide the Spotlight search field.Opens Terminal, Activity Monitor or System Settings by typing the name.
macOSCommand-QQuit the current app.Really quits an app – closing the window leaves most Mac apps running. Also closes a browser stuck on a scam page.
macOSCommand-Comma (,)Open settings (preferences) for the front app.Opens the settings of the app in front, for example the browser’s.
macOSShift-Command-5In macOS Mojave or later, take a screenshot or make a screen recording.Capture the exact error message for your fix log.
macOSControl-Command-QLock your screen.Before you walk away during a long repair step.
macOSShift-Command-QLog out of your macOS user account.Logging out and in again restarts your login items without restarting the Mac.
macOSControl–Command–Power buttonOn built-in keyboards without Touch ID, force your Mac to restart, without prompting to save any open and unsaved documents.Last resort when nothing reacts: unsaved work is lost. Macs with Touch ID are handled differently – see Apple’s page.
macOSControl–Power buttonOn built-in keyboards without Touch ID, show a dialog asking whether you want to restart, sleep, or shut down.Opens the restart, sleep and shut down dialog from the keyboard.
macOSShift-Command-UOpen the Utilities folder.The folder that holds Terminal, Activity Monitor and Disk Utility.
macOSCommand-TabSwitch to the next most recently used app among your open apps.Check which apps are open when one is hidden behind a full-screen window.
macOSCommand-POpen a print dialog so that you can print the current document.Opens the print dialog – the starting point of the Mac printer diagnosis.

Sources and how this page was made

The shortcuts were selected by hand; their key combinations and descriptions were then extracted by a script from the two pages below and are quoted unchanged (for long Apple entries, the first sentence). The “When it helps” column is ClickSolve Guide’s own. The shortcuts were not tried on physical devices for this page.
