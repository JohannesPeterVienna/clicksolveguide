What does this IP address tell me?

The address a device shows in its Wi-Fi details is a test result. 169.254.x.x means the router never answered. 192.168.x.x means it did. 100.64.x.x on a router means the provider shares one public address among customers. Type the address and get the range, the document that defines it and what follows for the diagnosis.

Why the address is a check that changes nothing

Reading an address needs no command and no setting: every system shows it in the details of the connected network. The Wi-Fi diagnosis asks for it at exactly one point – after other devices have been found working – because the answer splits the remaining causes in two: no address from the router, or an address but no traffic.

The check compares the address with the two IANA registries of special-purpose ranges. An address in none of them is a public address. The check never looks anything up online and does not find out “whose” address it is.

The example buttons use made-up addresses.

Sources and how this page was made

Ranges, registry names, RFC references and the “globally reachable” value were taken from the registries’ CSV files (footnote markers removed). The two multicast ranges marked with * were added from their RFCs. The column “What it tells you” is ClickSolve Guide’s own explanation of the definitions in RFC 1918, RFC 3927, RFC 6598, RFC 1122 and RFC 4291.
